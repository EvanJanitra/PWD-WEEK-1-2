A. Profil Saya

Halo! Nama saya Evan Janitra Prabandara Rauuf, Saya adalah mahasiswa aktif Program Studi Sistem Informasi di Fakultas Ilmu Komputer, Universitas Dian Nuswantoro. Bagi saya, teknologi informasi bukan hanya soal menulis kode, tetapi tentang bagaimana data dan sistem dapat dimanfaatkan untuk menghadirkan solusi nyata bagi kehidupan sehari-hari, asekkk.

Saya memiliki ketertarikan yang besar di dunia data, khususnya Data Analyst mulai dari mengolah, membersihkan, hingga membaca pola dari data untuk menemukan wawasan yang bermakna. Di sisi lain, saya juga sangat tertarik pada bidang Internet of Things (IoT) serta otomatisasi sistem dan alat. Menurut saya, melihat rangkaian perangkat keras dan perangkat lunak bekerja bersama secara otomatis adalah salah satu hal paling menarik dalam dunia teknologi. Perpaduan antara data dan IoT inilah yang ingin terus saya dalami, karena data yang dikumpulkan perangkat pintar dapat dianalisis untuk menghasilkan keputusan yang lebih baik.

Selain itu, saya juga menekuni pengembangan aplikasi web, perancangan basis data, dan pemodelan sistem, serta memiliki minat di bidang desain, videografi, dan fotografi. Di luar dunia akademik, saya gemar naik gunung dan berolahraga, seperti badminton, futsal, sepak bola, dan padel. Selama menjadi mahasiswa, saya terus berusaha meningkatkan pengetahuan dan keterampilan melalui berbagai tugas dan proyek perkuliahan, dengan harapan dapat berkembang menjadi lulusan yang siap berkontribusi di bidang teknologi informasi.

Halaman web ini dibuat menggunakan HTML5 murni tanpa menggunakan CSS untuk memenuhi instruksi pembuatan struktur dasar web. Dalam pembuatan halaman ini, saya menggunakan berbagai tag HTML untuk menyusun dan menampilkan informasi, serta mempelajari fungsi setiap tag agar dapat digunakan sesuai kebutuhan. Latihan ini menjadi pondasi bagi saya untuk membuat halaman web yang lebih kompleks di masa mendatang.

D. Proyek & Aktivitas Akademik
Tugas Proyek IoT (Automatic Eco-Friendly TrashBin)

Automatic Eco-Friendly TrashBin adalah proyek tempat sampah pintar berbasis Internet of Things yang dirancang untuk membuat pengelolaan sampah lebih praktis, higienis, dan ramah lingkungan. Tempat sampah ini dilengkapi sensor dan mikrokontroler sehingga tutupnya dapat terbuka secara otomatis tanpa perlu disentuh, dan kondisi tempat sampah dapat dipantau secara otomatis.

Melalui proyek ini, saya belajar merangkai perangkat keras (sensor, mikrokontroler, dan aktuator), menulis program untuk mengendalikannya, serta memahami alur kerja sistem otomatis dari pembacaan data sensor hingga aksi yang dijalankan alat. Proyek ini juga mengasah kemampuan saya dalam bekerja sama, memecahkan masalah saat pengujian, dan menghubungkan teori perkuliahan dengan penerapan nyata di bidang IoT.


Tugas Pemrograman Web 1

Proyek ini adalah pembuatan halaman profil dan form interaktif menggunakan HTML5 murni tanpa CSS. Halaman disusun dengan elemen semantik seperti header, nav, section, article, aside, dan footer, serta tabel terstruktur untuk menampilkan riwayat pendidikan.

Halaman ini juga dilengkapi form kontak dengan berbagai elemen input, seperti kolom teks, email, radio button, dropdown, checkbox, dan textarea. Melalui tugas ini, saya memahami fungsi setiap tag HTML, cara menyusun struktur halaman yang rapi, dan dasar pengiriman data form ke server, sebagai bekal untuk membuat aplikasi web yang lebih kompleks.
